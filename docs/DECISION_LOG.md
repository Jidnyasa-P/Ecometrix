# Decision log

| Decision | Why |
|---|---|
| One integrated workflow, not every sustainability topic | Depth over breadth; judged on a convincing end-to-end story |
| Pune pilot | Public, detailed tree census; open data portal |
| H3 hexagon grid, not wards | Census uses pre-2017 ward numbers; wards differ between datasets |
| Straight-line 300 m access, WHO 0.5 ha rule | Stated as linear distance; walking network later |
| Cost-effectiveness, never ROI | Green space earns no revenue here |
| Two interventions (pocket park, mini-forest) | Street trees and roofs need data that is not built |
| No carbon estimate for pocket parks | No Indian measurement found |
| Heat target NDVI from Pune's own mapped parks and forests | Data-derived instead of a borrowed constant |
| Exact optimiser (OR-Tools CP-SAT), pre-solved on a grid | Provable optimum; free web tier does no heavy compute |
| Need weights and equity share are visible policy presets | They are values, not facts |
| Marathi shipped with a visible "not yet reviewed" notice | Unreviewed machine-style translation must not look authoritative |
| Optimiser runs in the model step, not on the web server | Render free has 0.1 CPU and 512 MB |
